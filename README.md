ZENTIA — Doctor Appointment Booking System (MERN Stack)

📌 Overview

Zentia is a full-stack doctor appointment booking web application built using the MERN stack.
It is designed to streamline the process of booking, managing, and organizing medical appointments through a clean and user-friendly interface.

This project currently has a fully developed frontend, with backend services actively under development.

🚀 Tech Stack

Frontend:
React.js
Tailwind CSS

Backend (In Progress):
Node.js
Express.js
MongoDB
